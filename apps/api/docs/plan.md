# Plan

This project was created for educational purposes, and to help people experience easier access to anilist and allow search and redirection to other providers. Please keep in mind the rights of content creators and publishers—unauthorized sharing, violating ToS, or redistribution of content is prohibited.

We want to allow the user to create an account or login with anilist, we want a way to link their account and progress to anilist, and we want to allow them --when searching for a manhwa or a manga-- to search on other providers and map the progress that's done on the provider's manhwa to the manhwa in anilist.
